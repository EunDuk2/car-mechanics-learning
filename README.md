# AUTO ATLAS · 아반떼 N 상세 구조 탐색

2024 Hyundai Elantra N의 공개 3D 자산을 로컬에서 불러오는 자동차 구조 탐색기입니다. 초기 기본 도형 모델을 Ddiaz Design의 상세 표면 모델로 교체했습니다.

- 원본 258,192개 삼각형과 텍스처 보존
- 34개 탐색 그룹: 차체, 보닛, 도어, 실내, 엔진룸, 휠, 브레이크 등
- 연속 분해도, 보닛·도어·트렁크 열기, 투명화·단면·와이어프레임
- 부품 검색·필터·확대·숨기기·단독 보기
- 엔진룸·실내·브레이크 바로 보기와 출처를 포함한 PNG 저장
- 부품별 재현 범위와 출처 표시

**제조사 CAD가 아닙니다.** 게임 기반의 비공식 시각 모델이며, 차량 자산 자체에는 엔진·변속기 내부, 완전한 서스펜션·골격·연료 계통이 없습니다. 부품 그룹과 힌지는 탐색용 근사입니다.

## 실행

```sh
npm install
npm run dev -- --port 5173
```

http://127.0.0.1:5173/ 에서 확인합니다. 모델 파일은 `public/models/elantra-n.glb`에 있어 실행 중 외부 모델 다운로드나 로그인이 필요하지 않습니다.

## 검증

```sh
npm run build
node artifacts/check.mjs
```

브라우저 검증은 로컬 서버와 macOS Google Chrome이 필요합니다. `artifacts/validation.json` 및 스크린샷을 생성합니다.

## 기계 부품 상세 탐색

차량 화면의 **엔진 내부 상세 분해 / 서스펜션 상세 분해**에서 이동합니다.

- `/mechanics.html?system=engine`: 직렬 4기통 DOHC 엔진, 80개 선택 그룹. 피스톤 링·핀·로드 캡·밸브·스프링까지 개별 탐색.
- `/mechanics.html?system=suspension`: 한쪽 전륜 맥퍼슨 구조. 스트럿 내부·허브 베어링·브레이크 패드·하부 링크까지 탐색.
- 분해 슬라이더, 하우징 투명, 내부만 보기, 부품/계통 단독 보기, 숨김, 검색, 이름, 확대와 PNG 저장.

추가 형상은 부품 제조사 자료를 참고해 코드로 제작한 **일반 구조 참고 모델**입니다. 현대 CAD나 차량에서 추출한 내부 형상이 아니며, 실제 치수·정비 순서·전자제어 댐퍼 구조를 재현하지 않습니다. 기존 완성차 형상과 텍스처는 보존합니다.

## 엔진룸 전체 → 내부 상세

`/mechanics.html?system=bay`에서 엔진룸의 9개 계통·85개 선택 그룹을 탐색합니다. 엔진 본체를 선택하고 **엔진 내부 80개 그룹 탐색**을 누르면 기존 상세 모델로 들어갑니다. 스트럿 타워에서도 서스펜션 상세로 이동합니다. 상단 **엔진룸 전체** 경로로 돌아오면 선택·분해·표시·시점 상태가 복원됩니다.

에어클리너 케이스/필터/커버, 터보 하우징/회전축, 인터쿨러·라디에이터·팬, 펌프·호스, 인젝터·점화 코일, 배터리·퓨즈·제어기, 발전기·스타터, 보조 장치와 변속기 주변을 별도로 선택할 수 있습니다. 엔진룸 위에서 보는 시점도 제공합니다.

이 화면은 **주요 장치와 대표 연결을 포함한 참고 구성**이며 실제 아반떼의 모든 제조 부품·배관·장착 좌표를 복제한 것은 아닙니다. 엔진룸 안의 새 형상은 모두 코드로 재구성했습니다.

## 엔진 작동 학습

엔진 상세 화면은 일시정지된 **작동 학습**으로 열립니다. `반복 재생`을 누르거나 각도 슬라이더·네 행정 버튼으로 원하는 순간을 살펴보세요. 1×에서 네 행정 한 주기는 8초이며 실제 RPM을 나타내지 않습니다.

- 5단계 학습: 네 행정 → 왕복/회전 → 밸브 타이밍 → 밀봉/윤활 → 바퀴까지 동력 전달
- 피스톤·핀·링 왕복, 로드/캡 연결, 크랭크 회전, 캠축 절반 속도, 밸브/스프링 운동과 행정 표시
- 1번 실린더 집중 / 4기통 함께, 반복 재생·정지·속도·각도·다음 행정
- 80개 부품의 존재 이유·협동 관계·기능 상실 결과, 관련 부품 링크와 묶음 보기
- 단계별 이해 확인 문제와 해설

`부품 구조`로 돌아가면 기존 분해 탐색을 사용할 수 있습니다. 운동은 이상화된 기구 모델이며 실제 점화 진각·밸브 겹침·하중·연소·전체 구동계는 해석하지 않습니다. 검증 기록: `artifacts/engine-learning-validation.json`.

## 전체 계통 학습 확장

네 개의 상세 화면에 **230개 선택 그룹**, **24개 학습 단계**가 있습니다.

- 엔진룸 85개 / 9단계: 공기·터보, 냉각, 윤활, 연료·점화, 전원·제어, 제동 유압 공급, 보조 장치, 지지 구조, 구동계 연결
- 엔진 80개 / 5단계: 기존 학습 유지
- 전륜 29개 / 4단계: 스프링, 댐퍼, 마찰 제동, 현가·조향·구동 연결
- 동력·조향 36개 / 6단계: 단판 클러치, 20:40 기어쌍, 오픈 차동기어, 랙·타이로드, 타이어 접지

각 부품에서 존재 이유·협동 부품·기능 상실의 영향·관련 부품·학습 바로가기를 볼 수 있습니다. 완성차의 34개 표면 그룹에도 역할 설명과 관련 상세 학습 링크를 추가했습니다.

엔진 외 화면은 **작동 학습** 또는 왼쪽 단계로 시작합니다. 반복 재생·정지·속도·과정 슬라이더·단계 선택·이해 확인을 지원합니다. 유체·전기 흐름선은 기능 연결도이며 실제 배관·배선 경로/유량/전류가 아닙니다. 지지 부품은 연결 관계로 학습하며 움직임을 임의로 만들지 않습니다.

동력·조향은 기능별로 펼친 일반 구조입니다. 실제 차종의 6MT/8DCT 전체, e-LSD 제어, 후륜 기구, 전체 연료탱크/실내 공조/차체 내부, 모든 볼트·씰·클립·배선은 재현하지 않았습니다. 스프링은 축 방향 시험 지그, 조향은 일정 길이 링크의 평면 모델입니다. 제동거리·차량 거동·강성·유체 해석을 하지 않습니다.

검증: `artifacts/systems-validation.json` 및 `artifacts/system-*.png`.

## 엔진의 힘이 바퀴까지

`/mechanics.html?system=drivetrain&lesson=power-path`로 바로 엽니다. 동력·조향의 여섯 번째 학습 항목입니다. 기존 엔진의 다섯 번째 학습에서도 **엔진의 힘이 바퀴까지 · 전체 경로**로 이동할 수 있습니다.

엔진 → 클러치 → 변속기 → 차동기어 → 구동축 → 바퀴·노면, 여섯 단계의 설명과 빨간색 초점이 함께 바뀝니다. 엔진 모델을 재사용한 동력원과 전체 구동계를 동시에 보며 반복 재생할 수 있습니다.

클러치 연결/분리 비교: 분리하면 엔진은 계속 움직이고 출력측은 현재 위치에 고정합니다. 이는 토크 전달 차이를 보여주는 관찰 조건이며, 실제 차륜의 관성 주행을 계산하지 않습니다. 20:40 감속 뒤 추가 종감속은 1:1, 좌우는 직진 조건으로 가정합니다. 기능 배치와 흐름선은 실제 차종의 배치를 복제한 것이 아닙니다.

검증: `artifacts/power-path-validation.json`.

왼쪽 부품 목록의 **전체 선택**은 검색 필터와 관계없이 현재 구성의 모든 부품을 표시하고 빨간색으로 강조합니다. **선택 원복**은 전체 선택 직전의 선택 부품·숨김 상태를 복구합니다. 개별 부품을 클릭하면 단일 선택으로 돌아가며, 다른 상세 구성이나 학습 항목으로 이동하면 전체 선택 상태를 정리합니다. 차량 화면과 엔진룸·엔진·전륜·동력 전달 상세 화면에 공통 적용됩니다.

### 질문 · 답변 게시판

차량 / 상세 화면 상단의 **질문 · 답변**에서 질문을 남기고 답변을 기록할 수 있습니다. **현재 화면에서 질문**을 누르면 선택 부품과 진행 중인 학습 항목을 각각 연결합니다. 연결은 수정·추가·해제할 수 있으며, 연결을 누르면 해당 부품이나 학습 화면으로 돌아갑니다. 자유 태그, 질문·답변 내용 검색, 연결·태그 필터, 현재 화면 관련 필터, 답변 대기·답변 있음·해결됨 상태를 지원합니다.

현재 답변은 직접 작성하는 방식이며 AI 자동 답변과 다중 사용자 서버는 연결되어 있지 않습니다. 기록은 같은 출처의 브라우저 localStorage(`auto-atlas.questions.v1`)에 저장되어 차량 및 상세 화면에서 공유됩니다. 브라우저 데이터 삭제 시 사라지므로 **기록 내보내기**로 JSON 파일을 보관할 수 있습니다. JSON 자동 가져오기는 아직 제공하지 않습니다.

검증: `node artifacts/check.mjs --questions-only` — 질문·답변 저장, 태그 중복 제거·필터, 상태 변경, 수정 후 답변 보존, 연결 이동, 페이지 간 저장, 삭제 취소·실행, 작성 중 모달 재열기, HTML 문자 표시, 모바일 레이아웃.

### 엔진 조립 실습

`/assembly.html`은 학습 화면과 분리된 엔진 전용 조립 작업대입니다. 기존 엔진 모델의 **80개 선택 그룹** 전체를 사용합니다. 엔진 학습 상단 또는 차량 화면의 **엔진 조립 실습** 링크로 이동합니다.

- 보관함 부품을 드래그해 작업대의 원형 자리에 배치합니다. 놓은 부품도 다시 드래그해 이동할 수 있습니다. 작은 부품·모바일·키보드 조작은 부품 선택 → 자리 선택 → 배치를 사용합니다.
- 잘못된 자리, 자리 밖 임시 배치, 중복 배치가 가능하며 각 축으로 90도씩 방향을 바꿀 수 있습니다. 보관함으로 돌려놓기와 실행 취소도 지원합니다.
- 참고 형상·자리 힌트와 하우징 투명을 켜거나 끌 수 있습니다. 부품 간격을 0%로 줄이면 직접 조립한 엔진 형태가 나타납니다.
- **조립 검사받기**는 누락 / 다른 자리 / 자리 밖 / 기준 방향 / 같은 자리 중복을 검사합니다. 번호별 기준에 따라 채점하며 실제 부품의 상호 호환성, 정비 조립 순서, 체결 토크·공차·타이밍 위상은 판정하지 않습니다.
- 매 검사에서 당시 배치 상태를 별도로 보관합니다. 복습 메모, 부품 바로 선택, 검사 상태에서 재도전, JSON 내보내기가 가능합니다. 새 조립을 시작해도 검사 기록은 유지됩니다.
- 진행 중인 조립과 히스토리는 `auto-atlas.engine-assembly.v1` localStorage에 저장됩니다. 저장 오류는 표시되며 서버/기기 간 동기화 및 JSON 가져오기는 제공하지 않습니다.

검증: `node artifacts/check.mjs --assembly-only` — 실제 목록 드래그·작업대 이동, 모든 80개 UI 배치 및 원본 조립 좌표 일치, 정답·누락·오배치·방향·중복·자리 밖 판정, 실행 취소, 저장·새로고침·기록 복구·메모·내보내기, 모바일 화면.

조립 실습의 기본 진입은 **힌트 없는 도전**입니다. 부품 선택만으로 참고 형상이나 정답 위치를 표시하지 않으며, 자리 목록에는 부품 이름 대신 중립 번호를 표시합니다. 공통 자리 스냅은 잘못된 자리에도 적용되어 정답 여부는 검사 후 확인합니다. **이 부품 힌트 보기**는 요청한 부품만 표시하며 자동 배치나 정답 자리 선택은 하지 않습니다. **전체 정답 형상 보기**도 별도로 선택할 수 있습니다. 힌트를 끄거나 새로고침해도 사용 이력은 검사 기록에 남으며, 새 조립 시작 시 새 이력으로 시작합니다. 기존 조립과 검사 기록은 유지됩니다.

추가 검증: `node artifacts/check.mjs --assembly-hints-only` — 기본 정답 비노출, 부품 선택 후 비노출, 개별 힌트 범위·자동 자리 선택 없음, 힌트 해제 후 이력 보존, 재진입 기본 숨김, 새 실습 기록 초기화, 모바일 렌더링.
